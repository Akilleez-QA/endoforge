## Limits and choices

- The initial live orchestration failed and was not rerun successfully. Frozen-output continuation evidence must not be described as a clean live campaign run. Both failures and all continuation hashes remain available.
- Claude's tools were disabled. Codex was in its own read-only sandbox with web disabled; local tools were available, though its event stream records no tool calls. Adversarial accesses were real shell probes through the same bubblewrap mount specification; models were not asked to attack the boundary. This does not qualify hostile escape resistance, concurrent scheduling, `/proc`-level attacks or arbitrary CLI behaviour.
- Model networking remained enabled for subscription providers. No LAN or management-endpoint egress constraint exists. A minimal mounted home is visible to its own authenticated worker, including that worker's copied token; no secret-confidentiality claim is made against that worker.
- Gates ran on the trusted host with an external 90-second process-group timeout. Existing G6 remains a timing check, not a per-call preemption mechanism. Timeouts were not deliberately injected in this probe.
- Nested bubblewrap failed under the tested Docker restrictions. The message suggests namespace restrictions but does not uniquely identify kernel versus seccomp/user-namespace policy. Host bwrap works; the tested Docker-containing-bwrap topology is **not qualified**. Host bwrap and Docker-per-worker remain distinct alternatives. No capabilities or seccomp protections were weakened.
- P09 image had no bundled bwrap: test mounted host bwrap and host shared libraries read-only, solely to isolate the namespace question. This is not a self-contained hybrid image or a Docker live-agent qualification.
- No new infrastructure integration, capability promotion, full campaign, model-quality rate, portability/recovery, persistent sessions, encrypted backup or cross-host/architecture execution was established. P09 evidence and production/atomizer sources were untouched.
