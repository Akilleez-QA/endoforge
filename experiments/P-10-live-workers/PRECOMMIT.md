# P-10 live workers — PRECOMMIT

**Proposed, 18 October 2026.** Qualify one fully specified request through authenticated request-blind evaluator (Codex) then generator (Claude), with host-trusted frozen gates. This is a targeted operational probe, not a quality campaign or TX9 evaluation.

Request: export `celsiusToFahrenheit(c: f64): f64`, convert by `c * 9 / 5 + 32`, accept finite Celsius in inclusive [-273.15, 1000], trap for all other inputs. Numerical absolute error <= 1e-9. No defaults or additional inputs. Evaluator receives this request and a fixed test JSON schema only; no generator contract, kernel, glue, gate code or reference oracle. It must supply a compact suite covering ordinary values, both boundaries, out-of-range and NaN/infinities. Generator receives only the request and the AssemblyScript export requirement; no evaluator data. At most two model calls, each externally bounded at 180 seconds, no repair call.

Before any measurement, hash this file, canonical precommit.json, the runner, request, prompts, and trusted closed-form oracle. Each execution gets an exclusive attempt directory; never overwrite previous attempt evidence. Copy only each CLI's subscription auth into a mode-700 ephemeral home and delete finally. Model workers use established host bubblewrap minimal system/mise mounts and isolated homes, private outputs, separate role canaries, read-only request; provider networking retained with NO LAN egress restriction. No API key purchase, Docker socket, real host home or credentials in receipts/images.

Acceptance: both authenticated turns exit successfully with usage; evaluator suite is structurally valid, has required case classes and matches the trusted request oracle; freeze exact suite before generator starts; original fixed G1-G7 accept generated candidate, reject deliberately constant-32 candidate at G4; trusted independent oracle additionally checks deterministic valid and invalid inputs. Two actual role output/private trees exist before either worker, and before/after real shell probes in the same bubblewrap mounts must deny exact peer reads/writes and generator access to evaluator tests; own private/output access must succeed, request writes fail, canary hashes remain unchanged. Capture exact commands, exits, wall times, output digests and step receipts; classify nested model output as untrusted. Gate processes have an external 90-second timeout (G6 alone is not a watchdog).

Qualify nested bubblewrap in the existing pinned P09 Docker image, non-root, read-only root, no-new-privileges, all capabilities dropped, default seccomp, no network, bounded resources, tmpfs scratch. Mount host bwrap and its required libraries read-only if missing from image. Do not install packages, add capabilities, disable seccomp, use privileged or expose daemon socket. A bounded namespace failure is data, not reason to relax protections. Stop on missing auth/dependencies, timeout, unexpected filesystem access, malformed output, <5 GiB disk, or 10-minute total execution. Preserve failures. No production integration, promotion, source/gate edits, full campaign, checkpoint recovery or cross-host claim.

Every reported measurement is **Recorded (probe)**, one shared machine, one request, one turn per model family. Networking, hostile escape resistance, model quality rates, resource/performance comparison and a resumable campaign remain unqualified.
