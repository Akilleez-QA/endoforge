# P-12 revision 3: hard-killed controller reconciliation

Precommitted 18 October 2026, before measurement. Preserve revisions 1 and 2. Add a trusted per-attempt ownership journal, fsynced before Docker create, and an explicit host reconcile(root, attempt) API. Caller must establish controller death first. Reconciler validates identifiers, expected digest, token and exact token-derived name, touches only that journal's token-matching container, captures terminal state/logs before removal, and never publishes uncertain output. A fresh attempt may retry the same unpublished job. Existing publication matching the journal expected SHA is recorded as recovered without linking another artifact. Expected hashes remain trusted host policy.

Run bounded offline tests with existing immutable P-09 image: hard SIGKILL controller after observed Docker start; assert container survives controller death; externally reconcile and verify zero container/no publication; new-attempt retry succeeds exactly once. Simulate crash immediately before final result write, after atomic publication; recover publication by expected hash, preserving exactly one publication. Repeat reconciliation idempotently. Reject malformed journal before any Docker action. Record hashes of precommit/scripts before measurement, raw Docker commands, controller exits, environment before/after and outcomes. Stop at <5 GiB or 5 minutes; no network, model calls, system config or campaign changes.

Limits: supervisor scheduling and reliable detection of controller death are external; reconciliation must never run alongside an active controller. Local trusted-user filesystem only. fsync of journal and its directory requests durability but physical storage/fs/filesystem failure and parent-tree creation survival are not proven. Publication/final receipt remain separate operations; publication recovery supplies evidence of an existing digest-matching job artifact, not a durable transactional ledger or proof of which attempt originally linked it. No multi-host scheduler, power cut, daemon loss or arbitrary artifact directory recovery is claimed.
