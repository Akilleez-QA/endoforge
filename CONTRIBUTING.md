# Contributing to EndoForge

Thanks for your interest. The project is preparing for an open-source release, and the contribution process may change before then.

## How to contribute

1. Open an issue describing the problem or proposal before starting larger work.
2. Fork the repository and create a branch from `main`.
3. Keep each pull request small and focused on one change.
4. Run the test suite (see the README) and make sure it passes.
5. Open a pull request that explains what changed and why, with evidence such as test output or receipts.

## Conventions

Read [docs/CONVENTIONS.md](docs/CONVENTIONS.md) before editing documents. Claims carry evidence labels, and reconstructed documents say so at the top.

## Licensing of contributions

The project license has not been chosen yet. Contribution terms will be published with it.
