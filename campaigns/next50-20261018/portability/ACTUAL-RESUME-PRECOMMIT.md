# Actual campaign pending-stage resume

Resume an actual current campaign's pending deterministic Wasm verification or consumer execution stage after its completed model stages. No model invocation or credentials. The source stage owner supplies the actual state/artifact and source-backed frozen cases in resume.json (endoforge.portable-stage.v1). Preserve actual model stage receipts, frozen evals, references and source/runtime dependency identities in an age-encrypted checkpoint. Do not synthesize a historical kernel as fresh generation.

Run identical actual deterministic cases locally and on fieldops from encrypted checkpoint. Checkpoint source inventory must remain byte-identical. Remote execution uses pinned Wasmtime under existing bubblewrap network-disabled namespace. Validate finite numeric outcomes/tolerances and explicit unreachable refusals; fuel/runtime errors cannot count as domain refusals. Completed stages are retained and no model stage reruns. Resume twice to require one content-identical publication and an idempotent reuse record. Test corruption/wrong key without extraction. The stage receipt is deterministic; raw commands/timings live in separate exclusive attempt receipts. This does not claim two-family generation where unavailable, remote model authentication, or full pipeline Docker publication when only a consumer stage is resumed.
