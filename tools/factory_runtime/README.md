# Trusted host runtime v1

Local experimental control plane, not a deployed factory. Workers never receive Docker sockets, host home, journals, frozen peer suites or publication mounts.

## APIs

`runner.run_attempt(root,attempt,job,input_path,input_sha,expected_stdout_sha,script,timeout=3)` executes trusted host script in offline Docker, validates exact stdout digest and links one publication. Existing attempts/publications cannot be overwritten. `runner.capture_attempt(root,attempt,job,input_path,input_sha,script,timeout=3)` captures stdout without publishing or invoking it; caller validates captured content independently. Scripts are trusted supervisor code, never accepted directly from model artifacts.

`python -m tools.factory_runtime run ROOT JOB_SPEC.json`; exact version1 job fields: version, job, attempt, input, inputSha256, expectedSha256, script, timeoutSeconds. `python -m tools.factory_runtime reconcile ROOT ATTEMPT` recovers only a journal whose original PID/starttime/boot identity is dead; another live controller holds an exclusive flock. Unknown outcomes never promote staged output. Every attempt emits rich raw `result.json` plus strict version1 `record.json` receipt.

`egress.serve(private_unix_socket)` starts a trusted CONNECT proxy. `egress.role_worker_command(role,temp_home,unused_output_directory,socket,command,inputs={resource:path},freeze=None)` builds the isolated model-worker command; run using `egress.run_bounded(argv,timeout=180,output_limit=1048576)`. Role inputs must be declared by `core.ROLES`. Generator/repairer require host-validated `{version:1,frozen:true,suiteSha256:<digest>}`. Worker does not receive the frozen suite. Low-level `worker_command` is an implementation primitive and does not enforce role identity; integration uses role wrapper.

Named resources mount at `/in/<name>`. Model home64MiB/tmp64MiB/out8MiB are ephemeral tmpfs; no artifact files persist. Collect bounded stdout. Only temporary `.codex/auth.json` mounts read-only into home. Claude Code CLI is prohibited: the current wrapper neither discovers nor mounts its executable or credentials. Caller owns copying and deleting temporary credentials. Existing subscription tokens retain their provider authority; this is role-specific filesystem access, not newly narrowed provider scopes.

Each hosted worker gets its own unprivileged user/network/PID namespace, no routable interfaces, a bounded single-process asyncio loopback bridge to the Unix proxy, and a transient user systemd scope CPU100%, memory2GiB, swap0, tasks64. `/dev` is read-only (device nodes remain usable). Provider DNS is resolved on the trusted host, every returned address must be global, then numeric addresses are pinned for connection. Exact provider names/443 only; raw DNS, LAN, metadata, host and management endpoints cannot be reached directly or by CONNECT. Redirects to another authority must make another CONNECT and face the same policy. No payload/token logging. At most32 proxy threads per server; slow headers expire after10s.

`wasm.run(module,export='run',fuel=100000,memory=1048576,epoch='100ms',wall=2,args=None)` checks pinned Wasmtime49.0.3 SHA256 before invocation, enforces fuel/epoch/linear memory limits plus external process wall/CPU/file limits. It does not grant filesystem directories or networking. Numeric args follow the module path. Unknown imports currently fail closed; parent owns explicit permitted import adaptation before pure runtime use.

## Fixed Docker budgets

CPU1 core; RAM/swap512MiB;32 processes; tmp64MiB; out8MiB; logs1MiB rotation1 file. Read-only root, unprivileged UID/GID, all capabilities removed, no-new-privileges, networknone, immutable existing image digest. Docker commands are limited20s. Standard Docker device mounts and journal/receipt storage are trusted host infrastructure; no writable host data volume is mounted.

## Durability and scope

Before create, fsynced exclusive journal records attempt, original controller identity, random ownership token and exact token-derived container name. Container removal always verifies token, including fallback. Filesystem publication order: write+fsync artifact; fsync attempt directory; write+fsync validation receipt; check controller generation; no-overwrite hardlink; fsync publication directory and root; fsync terminal receipt. Kernel/OS crash durability is the filesystem's fsync contract; tested faults kill controller processes, not power to disks. Host administrative tampering is outside scope. Journals remain immutable; startup reconciliation is explicit `reconcile_all`, not an installed daemon. Successful attempts with a live original process are not crash-reconciled.

Scheduler is synchronous bounded FIFO batches (capacity1–8), with persistent blocked/running/terminal records and exponential subscription backoff. Interrupted running records become unknown and require trusted reconciliation. It never substitutes paid APIs/providers. It is not a multi-host queue.

Single-file artifact import rejects symlink/hardlink/socket/special files and oversized input. Mount trees reject link/special entries; no archive extraction is supported. Validation assumes the trusted supervisor owns staging and does not mutate trees between validation and mounting.
