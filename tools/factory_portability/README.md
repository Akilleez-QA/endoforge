# Portable campaign tools

`checkpoint.py pack SOURCE ARCHIVE --recipient AGE_PUBLIC_KEY` packages an allowlisted staging directory. `SOURCE/checkpoint.json` must declare:

```json
{"schema":"endoforge.checkpoint.v1","job_states":{"job":"generated"},"frozen_evals":{"path":"evals/frozen.json"},"dependencies":{"lock":"package-lock.json"},"references":{"manifest":"references.json"},"provenance":{"source_versions":"versions.json","runtime":"toolchain.json"},"credentials":"excluded-reauthenticate-at-destination"}
```

Each required metadata field is a nonempty object or list. Callers supply the real role schemas and checkpoint state. Pack computes an exact file inventory (SHA256, byte size and executable bit). It refuses symlinks, hardlinks, nonregular entries, credential-scoped paths and common secret markers. **Use an explicit allowlisted staging tree; this scanner cannot detect arbitrary secrets.** Encrypted archives use age X25519 recipients. age performs authenticated decryption before any extraction; all uncompressed tar member paths/types/identities are validated before atomic Linux `renameat2(RENAME_NOREPLACE)` publication. Existing archive/destination never overwrites. A checkpoint is capped at 512MiB; provision the toolchain as a separately content-pinned bundle. Plaintext is buffered in memory (not disk) during encryption/decryption; callers remain responsible for source file permissions. Checkpoint creation is for quiescent/fenced snapshots; this module does not freeze a running supervisor or validate role authority by itself.

`checkpoint.py unpack ARCHIVE EMPTY_DEST --identity FILE` restores. `--identity -` supports ephemeral identity over an authenticated SSH connection without copying an identity file remotely. Keep private keys outside campaigns and logs. Promotion authority is reconstructed deliberately at destination; checkpoint state alone is not authorization to publish.

`bootstrap.py prepare ROOT EMPTY_BUNDLE --node NODE_BINARY --npm NPM_PACKAGE_DIR --wasmtime WASMTIME_BINARY` provisions a standalone, content-pinned Node/npm/Wasmtime/compiler bundle. It copies only pinned runtime distribution bytes, original package lock/source gate and nonsecret replay fixtures, then fetches compiler dependencies with npm scripts disabled into an empty dependency directory/cache. `toolchain.json` hashes every byte and symlink. `bootstrap.py verify BUNDLE` detects changes; `bootstrap.py replay BUNDLE EMPTY_DEST` copies the offline npm cache and reinstalls into a fresh directory with `npm ci --offline --ignore-scripts` before compiling/gating 19 expected historical artifacts. Registry access occurs only during trusted prepare. Run offline workers under a network-disabled boundary; npm offline alone is not a firewall.

`second_host.py BUNDLE EMPTY_RECEIPT --host fieldops` transfers a SHA256-checked nonsecret bundle to a UUID-owned `/tmp` directory on the existing SSH host. It refuses the same hashed machine-id, executes fresh offline replay inside bubblewrap with network isolation, and retains only the toolchain pending a real partly completed campaign. It does not complete cross-host campaign recovery itself. Cleanup is restricted to the exact receipt-recorded owned staging path. No packages, daemons or desktop settings are changed.

`qualify_wasmtime.py BUNDLE` verifies executable content and runs known-good, infinite loop and trap controls. `test_checkpoint.py` exercises encrypted roundtrip and hostile inputs with generated identities removed afterward.

Platform: Linux x86_64, compatible glibc, Python3 standard library, age/age-keygen for checkpoint tooling, and Linux renameat2. Bootstrap additionally assumes standard `/usr/bin/env` and shared libraries. Node 22.18.0, npm12.0.2, AssemblyScript0.28.20 and Wasmtime49.0.3 were qualified together for this exact lockfile; broad npm/Node compatibility and bit-identical OCI images are unqualified.

`resume_stage.py CHECKPOINT BUNDLE OUTPUT` resumes a parent-frozen pending deterministic Wasm consumer/verification stage. `resume.json` identifies the exact stage already pending in real `job/state.json`, module content hash and cases (`fn`, numeric `args`, expected finite value/tolerance or explicit `expectError`). Every checkpoint payload hash is checked before and after. Runtime errors and fuel exhaustion cannot masquerade as domain refusals. A fsynced temporary receipt is published by exclusive hardlink; the exact second resume records reuse rather than duplicate publication. Its resumed state preserves all completed stages and removes only the completed pending stage. Detailed attempt executions remain separate from deterministic publication bytes.

`campaign_transfer.py STAGED_CHECKPOINT BUNDLE EMPTY_RECEIPT --identity PRIVATE_IDENTITY --remote OWNED_REMOTE_TMP` handles actual encrypted transfer, local/remote completion, idempotency and exact publication/module comparison. It may generate the private identity at the explicitly chosen custody location with mode0600; the key remains outside the repository. Only ciphertext and nonsecret trusted driver bytes go to remote staging. Identity bytes stream through SSH to age `--identity -`, never via argv/logs or a remote key file. Decrypted local input is retained under ignored `work/`. Successful returned receipts precede removal of the exact owned staging tree. No model stage or credential is required for this narrow offline resume. A failed attempt retains its own diagnostic state for explicit followup.

`prepare_actual.py EMPTY_STAGE` is the immutable, case-specific preparation recipe for the authorized current `dev-affine-01` live campaign, preserving both actual model-family eval receipts, generation receipt, full frozen job, source versions, image provenance, dependencies and optional reference fixture. Its four consumer cases are independently frozen before execution. This recipe is evidence for this job rather than a generic job-discovery API. `test_remote_checkpoint.py` records a one-shot synthetic transport preflight against the receipt-owned remote namespace; that namespace is removed after actual completion, so this historical preflight cannot be rerun as-is. `test_resume_stage.py BUNDLE` is the portable synthetic local driver control and does not count as N40 evidence.
