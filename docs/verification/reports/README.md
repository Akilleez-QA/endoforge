# Test reports

Each test report (STR) records the runs of `make test` and `make test-optimized` at one commit, generated by
`tools/gen_release_docs.py` from the recorded logs. Procedure: [test plan TP-5](../test-plan.md#tp-5--release-records).
A report applies only to its commit. No release tag exists yet; reports are named `STR-main-<date>`.
