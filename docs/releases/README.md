# Version descriptions

Each version description (VDD) identifies one recorded state of EndoForge: commit, contents, build steps, digests,
changes and open problems. They are generated by `tools/gen_release_docs.py` together with the matching
[test report](../verification/reports/README.md). No release tag exists yet; records are named `VDD-main-<date>`.
