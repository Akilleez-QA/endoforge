# Version descriptions

Each version description (VDD) identifies one recorded state of EndoForge: commit, contents, build steps, digests,
changes and open problems. They are generated by `tools/gen_release_docs.py` together with the matching
[test report](../verification/reports/README.md). No release tag exists yet; records are named `VDD-main-<date>`.

Known error in a generated record: [VDD-main-20261108](VDD-main-20261108.md) §8 says "CI has no secret-scanning job".
The CI job `secret-scan` in `.github/workflows/ci.yml` already ran Gitleaks then; the sentence was hard-coded in the
generator. Since round 8 the generator reads the workflows, so the next record states it correctly (finding D-13 in the
[assurance record](../assurance/assurance-record.md)). Generated records are not edited by hand.
