# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems. Use GitHub's private vulnerability reporting ("Report a vulnerability" under the Security tab), or contact the maintainers at the address to be listed here before public release.

Include a description, steps to reproduce and the affected commit. We aim to acknowledge reports within 5 business days.

## Supported versions

EndoForge is preproduction. Only the latest `main` is supported.
